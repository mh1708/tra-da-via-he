# Trà Đá Vỉa Hè

Quán trà đá vỉa hè 3D chạy trên trình duyệt (Three.js). Một file `index.html`, không cần build.

- Chọn nhân vật, đi lại trên vỉa hè, ngồi ghế nhựa.
- Gọi trà: cô Hoa rót trà đá rồi đưa cốc.
- Chém gió bằng câu có sẵn, cắn hướng dương, cụng ly.
- Ô ủng hộ chủ quán bằng mã VietQR.

Bản này chạy một người. Phần ngồi chung bàn và sổ nợ chung sẽ thêm sau (Supabase).
